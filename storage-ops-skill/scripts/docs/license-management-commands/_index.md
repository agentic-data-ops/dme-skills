# License Management Commands

License files are authority credentials for value-added functions such as snapshot, remote replication, clone, and SmartQoS. License management commands are used to import and query the license files.

## license

- export license: **export license** files.
- import license: **import license** files. You can activate or update license files by running this command.
- show license: query information about the function configuration of the imported license files.
- show license_active: query information about active licenses.
