# Container Management Commands

Container management commands are used for container deployment, management, and usage. The functions of this type of commands include activating, re-activating, deploying, starting, stopping, and querying the container service, adding and querying container nodes, as well as installing, querying, modifying, and deleting container applications.

## container_application

- change container_application general: update an application.
- change container_application view: enter the container OS.
- create container_application general: deploy an application.
- delete container_application general: delete an application.
- show container_application dynamic_config: query the configuration items that can be configured for deploying a chart package.
- show container_application general: query the list of available chart packages or the list or details of deployed applications.

## container_node

- show container_node general: query container node information.

## container_service

- add container_service general: add container service resources.
- change container_service active: activate the container service for the first time.
- change container_service general: change the status of a container service.
- create container_service general: create container service resources.
- show container_service general: query container service information.
